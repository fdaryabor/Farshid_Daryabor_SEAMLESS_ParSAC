# Farshid_Daryabor_SEAMLESS_ParSAC

This repository is part of my contributions to the SEAMLESS Project (https://seamlessproject.org/) under the CMEMS Arkona Site in the Baltic Sea. It includes code and outputs for:

- Running the 1D GOTM-ERGOM model
- Analyzing the observability of target indicators
- Conducting parameter sensitivity analysis

The work here supports project deliverables, documented at:
 https://seamlessproject.org/Outputs/Deliverables.html

**Folders:**
- `parsac`: Parameter sensitivity (ParSAC-GOTM coupling)
- `python_analysis_scripts`: Observability analysis
- `RESULTS_SENSITIVITY`: Output sensitivity results
- `ONEYEAR_INDICATORS_OBSERVATION`: One-year indicator CVs
